# Security

To report a suspected vulnerability, use the repository's **Security →
Report a vulnerability** option if available, or contact the maintainer
privately. Include the commit or deployed version, affected feature, and
expected and observed behavior. Use a copy with synthetic document text
and remove OAuth tokens, private references, and personal data from reports.

The add-on's permissions, document data flow, and storage are documented in
[Privacy](docs/PRIVACY.md). The [Sefaria review guide](docs/for-sefaria-review.md)
covers release verification and outstanding approvals.
